# CONTROL ESCOLAR

## Descripción
Sistema web para la gestión escolar de una institución educativa, 
que permite administrar alumnos, profesores, administrativos y directivos.

## Objetivo
Desarrollar una aplicación que centralice el control de inscripciones, 
calificaciones, pagos, becas y reportes académicos.

## Pila Tecnológica
- Laravel (PHP)
- MySQL
- HTML / CSS / JavaScript
- Bootstrap

## Equipo de Desarrollo
| Nombre | Módulo |
|--------|--------|
| Integrante 1 | Alumnos |
| Integrante 2 | Profesores |
| Integrante 3 | Administrativos |
| Integrante 4 | Director / Secretario |
